# Accenture Financial Analysis

## 📊 Project Overview

This project presents a financial analysis of Accenture Ltd. to evaluate its financial efficiency and corporate performance.

The analysis focuses on key areas including profitability, liquidity, solvency, and operational efficiency using financial statements and financial ratios.

## 🎯 Objectives

- To analyse the financial performance of Accenture Ltd.
- To evaluate profitability and liquidity.
- To assess solvency and operational efficiency.
- To interpret financial ratios and understand overall corporate performance.

## 📅 Period of Analysis

FY 2021 – FY 2025

## 🔍 Key Areas of Analysis

- Profitability Analysis
- Liquidity Analysis
- Solvency Analysis
- Operational Efficiency
- Financial Ratio Analysis

## 🛠️ Tools & Skills

- Microsoft Excel
- Financial Statement Analysis
- Financial Ratio Analysis
- Data Analysis
- Business Analytics
